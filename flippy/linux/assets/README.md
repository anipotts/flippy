# Provider identification assets

Copies of `flippy/mac/assets/claude.png` and `openai.png` (the Linux download doesn't include `flippy/mac`).
They identify the optional providers in Flippy's setup window; they are not Flippy branding or an endorsement.
Where they came from, how they were rendered and the owners' usage terms: `flippy/mac/assets/README.md` in the
repository.

- `claude.png`: Anthropic's Claude site icon. The trademark remains Anthropic's.
- `openai.png`: the ChatGPT site icon as a white monochrome rendering. OpenAI's marks remain OpenAI's property
  (<https://openai.com/brand/>); used only to identify the related service, without implying sponsorship.
